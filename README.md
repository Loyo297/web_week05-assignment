# SpendWise - Personal Budget & Expense Tracker

## Project Description

SpendWise is a personal budget and expense tracking dashboard designed to help users understand and manage their spending.

The project started as a static dashboard using HTML and CSS. JavaScript was then added to allow the application to collect user information, store budget and expense data, perform calculations, and display the results in the browser console.

The project uses:

- HTML
- CSS
- JavaScript
